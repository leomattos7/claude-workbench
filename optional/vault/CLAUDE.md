## Vault (second brain)

Content knowledge lives in `{{VAULT_PATH}}` (rules in its `CLAUDE.md`, skill `vault`).
- A question about something the user already read or saved → check the vault before answering from memory.
- A valuable source shows up in a session → offer to ingest it (do not ingest without an OK).
- The vault is empty, or the user wants to fill it from repos, sessions, decisions or docs → offer the guided bootstrap (skill `vault`).
- Vault = knowledge; project docs = technical memory of a repo; Claude's auto-memory = preferences.
