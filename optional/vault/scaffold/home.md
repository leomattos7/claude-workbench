# Vault

[[index|Catalog]] · [[log|Log]] · `inbox/` for quick notes · `raw/web/` receives the Web Clipper

> [!tip] How to feed it
> - **Article/page:** Web Clipper with the `raw-web` template (`tools/web-clipper-raw-web.json`) lands in `raw/web/`.
> - **Your own idea or note:** create a new note (goes to `inbox/`, template `note`).
> - **PDF, transcript, any file:** drop it in `raw/`.
> - Then ask Claude: "ingest raw" or "ingest the inbox".
